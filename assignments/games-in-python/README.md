
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras usando strings, loops e entrada de dados do usuário em Python. Pratique também condicionais e seleção aleatória ao controlar o progresso e o encerramento da partida.

## 📝 Tarefas

### 🛠️ Jogo da Forca

#### Descrição

Crie um jogo da Forca onde o jogador adivinha letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou derrota ao final da partida.
